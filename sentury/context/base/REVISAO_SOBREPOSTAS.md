Skills suas que parecem tratar quase da mesma tarefa, com o texto de cada uma:

{pares}

Duas skills para a mesma tarefa dividem o que se aprende, e uma acaba velha. Se as duas cobrem mesmo a mesma tarefa, leve para a que fica o que só a outra tem, com `aprender_skill` (`acrescentar`), e aposente a que sobrou (`aposentar`). Se são tarefas diferentes, deixe como está. `desfazer` volta qualquer um desses passos.
