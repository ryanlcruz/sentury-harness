# Regra do que vira artefato

O Workbench guarda **saídas reutilizáveis**, não pedaços da conversa. Um item
merece sobreviver ao turno quando faz sentido reabri-lo daqui a dias, tem uma
identidade própria e foi produzido como entregável ou escolhido por você.

| Entra no Workbench | Fica somente na conversa |
|---|---|
| arquivo ou anexo produzido pelo backend | tabela ilustrativa no meio de uma explicação |
| plano ou workflow persistido, porque atravessa turnos | bloco de código, comando, SQL, JSON ou HTML mostrado para explicar algo |
| tabela que você levou pelo botão **Abrir no painel** | trilha de execução, pensamento, telemetria ou resultado intermediário |
| anexo que você escolheu abrir no painel | resumo de ferramenta e conteúdo que só faz sentido naquele turno |

Fechar uma aba do Workbench não apaga o artefato. Descartar é outra ação e
precisa ser explícita.

## Tabelas

Nenhuma tabela da conversa vai sozinha para o Workbench. Cada uma traz o botão
**Abrir no painel**, e a decisão é sua. Adivinhar pelo texto do pedido
("monte uma tabela", "gere um relatório") só reconheceria quem escreve em
português com a grafia certa, e trataria menção como pedido.

Planilha e CSV de verdade vêm das ferramentas de exportação: o backend devolve
o arquivo, e o arquivo entra no Workbench como qualquer anexo.
